# UEAS Governance

UEAS v2.0 is an open-source standard and reference platform licensed under **Apache License 2.0**.

## Decision Making

- **Architectural Decisions:** Recorded as ADRs in `spec/adr/`.
- **Breaking Spec Changes:** Proposed via lightweight RFCs in `spec/rfcs/` and validated against the reference engine and UCTS conformance suite before ratification.
- **Contributions:** Accepted via Pull Requests with DCO `Signed-off-by:` and all CI quality gates green.
